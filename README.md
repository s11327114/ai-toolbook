# AI Toolbook - 個人 AI 工具實戰手冊

這是一個採用純 HTML5 與 Tailwind CSS 建構的靜態知識庫網站，旨在系統性地記錄各種 AI 工具的核心功能、適用場景與實戰提示詞（Prompts）。

## 專案特色
- **零建置工具依賴**：純靜態網頁架構，可直接部署於 GitHub Pages。
- **AI 協作友善**：根目錄內建完整的 `AGENTS.md` 開發規範，讓 AI 助手能依據統一的視覺系統與模板快速擴充新工具頁面。

## 目錄結構
- `AGENTS.md`：AI 協作與頁面擴充規範文件
- `index.html`：網站首頁與工具分類篩選總覽
- `tools/`：各個 AI 工具的獨立實戰介紹頁面
